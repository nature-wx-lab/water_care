# うるおい管理ナビ

気象庁の観測・予報データと栽培条件から、植物のうるおい残量、水やり判断、メダカ容器のあふれリスクを約5km格子で確認するNature Wx Labのβ版ツールです。

## 公開状態

- β・開発中
- 検索エンジン向け `noindex`
- 計算配列は全国31,296格子、地図表示と全国集計は日本陸域12,404格子
- うるおい残量／水やりナビ／根腐れ注意／メダカあふれリスク
- 地点詳細、7日カレンダー、端末内マイデータ、PNG保存、共有URL

## データと注意事項

出典は気象庁ホームページ、国土地理院およびNatural Earthです。表示する管理指標は、気象データと選択条件から機械的に計算した園芸・メダカ管理の目安であり、気象そのものの独自予報や防災情報ではありません。

陸域判定はNatural Earthの国境データと既存の都道府県割当から作成した固定マスクを使います。元の国境形状は公開物へ含めず、1格子1バイトの分類結果、作成条件、件数およびSHA-256だけを公開しています。

観測データが2時間超、予報データが12時間超更新されていない場合は、画面に「更新遅延」と表示します。閲覧中は同じデータ版へ固定し、新しいデータを検知した場合は再読み込みを案内します。

マイデータは利用者のブラウザ内だけに保存されます。選択地点は約5km格子IDとして扱い、生の緯度経度や登録内容をサーバーへ送信しません。

### マイデータの水やり再計算

植物アイテムの「たっぷり水やり」と「軽く水やり」は、記録を公開時別データの最初の対象時刻へ切り上げ、その時刻から先だけを再計算します。「たっぷり」は残量95%へ更新し、「軽く」は40ポイント加算（上限100%）した後、モード別の未丸め毎時水収支 `water_balance` を順に適用します。再計算用配列は登録された植物モードを表示するときだけ読み込みます。

公開時別データより古い、または提供終端より後の水やり記録は端末内へ保持しますが、現在の再計算には使いません。週間傾向のうち時別データ終端より後も個別記録は未反映です。かんたん補正、雨よけ記録、メダカの水換え・足し水は、現時点では物理再計算へ接続していません。

登録名・履歴などのマイデータはIndexedDBとJSON入出力だけで扱います。再計算時の通信は公開済み気象配列の取得だけで、マイデータを共有URLやネットワーク要求へ付加しません。
